# Data snapshot

The two CSV files are a hand-transcribed snapshot of the [Vellum LLM Leaderboard](https://www.vellum.ai/llm-leaderboard), which displayed “updated 1 Jul 2026” when accessed on July 18, 2026.

- `models.csv` contains the displayed Humanity's Last Exam (HLE) scores and price specifications used by the overall ranking and cost chart.
- `task_scores.csv` contains the displayed top-five scores for six task leaderboards; the simplified story uses three representative tasks.

Blank fields mean that Vellum did not display a measurement, and the visualization never imputes those missing values.

Vellum states that its leaderboard combines public benchmark results reported by model providers with independent evaluations run by Vellum or the open-source community. Consequently, these values should be read as a time-bounded comparison rather than permanent model characteristics.
